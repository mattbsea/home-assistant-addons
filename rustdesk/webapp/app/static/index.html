This dashboard shows server status and connection details. It is not an in-browser remote-desktop viewer — Home Assistant's ingress can only proxy a single HTTP/WebSocket port, and RustDesk's remote-desktop protocol needs raw TCP/UDP on the ports below. Install the native RustDesk client on the machines you want to control from, or use the official web client once you've forwarded the ports below to this add-on.
